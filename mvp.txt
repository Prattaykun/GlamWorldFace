Beauty Pageant Competition Platform – MVP Documentation
Project Objective
Build a web-based beauty pageant competition platform where contestants can join competitions and compete in two different modes:
1.	Jury-based competitions 
2.	Public voting competitions 
The platform should allow contestants to create profiles, upload images, participate in competitions, receive scores or votes, and display rankings/leaderboards.
The application should be developed as an MVP using a simple, scalable, and low-cost architecture.

3. Public User

Competition Types
A. Jury Competition
Contestants submit:
•	profile 
•	images 
•	personal information 
The system evaluates contestants and generates scores.
Leaderboard should be generated using the stored score values.
________________________________________
B. Public Voting Competition
Public users can vote for contestants.
Rules:
•	one account can vote only once per competition 
•	duplicate voting should not be allowed 
Leaderboard should be generated using vote count.
